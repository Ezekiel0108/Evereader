# Evereader
## What is it?
It is an esp32-s3 module based e-reader with dual screens that should be easy enough for anyone to build and customize.
### Why does this project exist?
There are two main reasons:
1. I really wanted to make a project bigger than what i had done until now, i want to give back at least in some way to the foss community;
2. I have been getting a lot into reading lately and i really wanted an e-reader, but none of them actually felt right for me, either they where too big to put in a pocket or the smaller ones just didn't fit enough content for my taste.
### Why two screens?
1. Why not?
2. I really wanted to keep the form factor pocketable without sacrificing text on screen, so i put two!

I am currently just ending the breadboard circuit, after that i want to start making the PCB and develop the firmware.
